# AgroCare Dataset Sample

This folder contains a small representative sample of the PlantVillage color dataset used for the AgroCare crop disease diagnosis project.

## Dataset Source

- Source: PlantVillage Dataset
- Original repository: https://github.com/spMohanty/PlantVillage-Dataset
- License: CC BY-SA 3.0
- Original paper: Mohanty, S. P., Hughes, D. P., & Salathé, M. (2016), "Using Deep Learning for Image-Based Plant Disease Detection"
- DOI: https://doi.org/10.3389/fpls.2016.01419

## Sample Contents

- 38 crop/disease/healthy classes
- 5 representative images per class
- Total: 190 images

## Purpose

The sample demonstrates the class-folder structure and actual image data used during dataset preparation for AgroCare.

The complete PlantVillage dataset is stored locally because of its large size. This GitHub folder contains a representative sample rather than the complete dataset.

## Dataset Verification

The complete locally collected dataset contains:

- 38 classes
- 54,305 images
- 0 unreadable images during OpenCV verification

All locally collected images were successfully read using OpenCV's image loading functionality.
